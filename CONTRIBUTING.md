# Contributing

Keep the project runnable with Python's standard library alone. No runtime downloads, model services, native extensions, package installation, or hidden dependencies. Run `python -m unittest discover -s tests -v` before proposing a change.

Every finite experiment must declare its parameter space and keep every requested output. Retain constant states, repeated points, degenerate projections, angular comparison misses, and results that appear uninteresting. Refuse resource bounds explicitly rather than silently clipping a shape or shortening a trajectory. An interrupted run must not be labeled complete.

Do not fill `human_interest`, `ai_interest`, `compressibility`, or `divergence_note` merely because a result looks interesting. Use explicit, attributed observer events. Unknown is `null`, never `false`. AI-generated code is not an AI interest judgment.

Label executed results `OBSERVED`, explicit calculations from recorded values `DERIVED`, and untested ideas `PROPOSED`. These labels describe provenance, not certainty or scientific importance. A numerical angle match is not a demonstrated biological or physical explanation. Preserve both matches and misses, measurement conventions, tolerance, source references, and degenerate cases.

Original contributions are submitted under CC0 1.0 Universal. Keep personal information and credentials out of the public repository. Add voluntary co-authorship attribution when appropriate.
